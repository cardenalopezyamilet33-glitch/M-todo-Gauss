# Método de Gauss en Java

## Lenguaje de programación
Java

## Cómo compilar y ejecutar
1. Descargar los archivos .java y ponerlos dentro de una carpeta llamada Ecuaciones_Lineales.
2. Desde la carpeta que contiene Ecuaciones_Lineales, compilar:
   javac Ecuaciones_Lineales/*.java
3. Ejecutar:
   java Ecuaciones_Lineales.Lanzador

## Ejemplo de prueba
Matriz de entrada (aumentada [A|B]):

3.0  -0.1  -0.2 |  7.85
0.1   7.0  -0.3 | -19.3
0.3  -0.2  10.0 |  71.4


Salida en consola:

SOLUCIONES DEL SISTEMA:

x1=3.0
x2=-2.5
x3=7.000000000000002
